# Telecom Customer Churn & Revenue Analysis

> **Work in Progress**

This project analyzes customer growth, recurring revenue, customer engagement, support interactions, subscription characteristics, and churn behavior for a simulated telecommunications company.

The analysis is being developed using **Python, SQL (SQLite), and Tableau** with the goal of identifying trends in customer retention and revenue and translating those findings into actionable business recommendations.

## Current Status

The SQL and Python analysis is currently in progress. The project currently includes analysis of:

- Monthly active customers
- Monthly recurring revenue (MRR)
- Average revenue per user (ARPU)
- Customer additions
- Customer churn
- Net customer growth
- Churn by customer segment
- Churn by subscription plan
- Churn by contract type
- Churn by support-ticket activity
- Churn by ticket volume and resolution status
- Churn by customer demographics
- Churn by data usage
- MRR by customer segment
- MRR by subscription plan
- Usage trends leading up to churn
- Consolidated churn-risk indicators
- Business recommendations based on the analysis

## Key Areas of Investigation

The analysis focuses on two primary business questions:

1. **How is the customer base and recurring revenue performing?**
2. **What customer characteristics and behaviors are associated with churn?**

The project examines both high-level business KPIs and more detailed customer-level patterns to develop a clearer understanding of the factors associated with customer retention.

## Planned Next Steps

The project is still under development. Planned additions include:

- Finalizing the analytical notebook
- Reviewing and refining the analysis
- Building an interactive **Tableau dashboard**
- Creating an executive-level dashboard summarizing the most important KPIs and findings
- Connecting the dashboard to the key churn and revenue insights identified in the analysis

The Tableau dashboard will be added to this repository once the project is complete.

## Disclaimer

This project uses a simulated telecommunications dataset and is intended as a portfolio project demonstrating data analysis, SQL, Python, visualization, and business problem-solving skills.
